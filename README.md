## ✨ Features

- Multi-platform posting
- SEO audit tools
- Content calendar
- Engagement automation
- Performance tracking
- AI content generation

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn
- API keys (Google AI, OpenAI, etc.)

### Installation
```bash
git clone https://github.com/ZOOKA-AI/social-media-automation-seo.git
cd social-media-automation-seo
npm install
```

### Configuration
Create `.env` file:
```env
API_KEY=your_api_key_here
```

### Usage
```bash
npm start
```
